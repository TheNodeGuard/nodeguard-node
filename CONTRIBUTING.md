# Contributing

Thanks for helping. A few simple rules:

1. Open an issue first for anything bigger than a small fix, so we can agree on the approach.
2. Keep to Python's standard library. `cryptography` is optional and must stay optional.
3. Run the checks before sending a pull request: `python3 tests/test_node.py`
4. Write messages and on-screen text in plain, simple English.

By sending a pull request you agree your change is shared under this repo's licence (AGPL-3.0).

This repo is updated from NodeGuard's main code at each release. Accepted changes are added there too, so they're kept in the next release.
